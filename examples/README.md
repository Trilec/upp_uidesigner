# Examples

Standalone Designer usage/integration examples belong here.

There is no genuine Designer example package yet — the `upp_Ui/examples`
demonstrations are not part of this repository. The production packages live
under `../UiDesigner` and the deterministic validation packages live under
`../tests`.

Intended content for this directory, when added:

- minimal examples that open the catalog, build a session, and export a package;
- integrations showing how generated UI packages are consumed from a separate U++ application;
- reference projects that use `UiDesigner` packages as external dependencies.
